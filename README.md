# Li Game Academy · 老李游戏学院

English | [简体中文](README_ZH.md)

Learn game development by building real projects, sharing what works, and improving together.

Li Game Academy is a game development education and open-source community led by Lao Li. We create practical Godot 4 tutorials, playable examples, reusable tools, and development breakdowns for independent developers. Our repositories include both GDScript and C# projects.

## Start learning

- [Tutorial library](https://github.com/LiGameAcademy/laoli_gamedev_godot4_course): written tutorials, paired project repositories, and course materials covering Godot fundamentals, ARPGs, dialogue and quests, RTS games, turn-based combat, and more.
- [Godot tutorial examples](https://github.com/LiGameAcademy/godot_tutorial_examples): examples accompanying the introductory Godot course.
- [IndieGameWatch](https://github.com/LiGameAcademy/IndieGameWatch): breakdowns of indie game design, development, and art.

Most written course materials are currently in Chinese. Translation coverage varies by repository.

| Project | Focus |

### Games and learning demos

- [GodotRogueMatcher](https://github.com/LiGameAcademy/GodotRogueMatcher): a five-in-a-row puzzle with roguelite skills and builds; also an AI-assisted development tutorial project.
- [Nutbound](https://github.com/LiGameAcademy/nutbound): a woodland roguelike deckbuilder following an acorn searching for a home.
- [Simple ARPG](https://github.com/LiGameAcademy/godot_simple_arpg_demo): an action RPG learning demo.
- [Tower Defense](https://github.com/LiGameAcademy/GodotTowerDefense) · [C# demo](https://github.com/LiGameAcademy/godot_tower_defense_cs): tower defense learning projects.
- [Tappy Plane](https://github.com/LiGameAcademy/GodotTappyPlane) · [2D Platformer](https://github.com/LiGameAcademy/GodotPlatform2D) · [Inventory UI](https://github.com/LiGameAcademy/GodotSimpleInventory): focused examples for learning by doing.
- [Godot Warcraft 3](https://github.com/LiGameAcademy/godot_warcraft3) · [RTS Kernel C#](https://github.com/LiGameAcademy/rts_kernel_cs): RTS implementation and architecture experiments.

Projects are at different stages of development. Check each repository for its supported Godot version, setup instructions, license, and current status.
