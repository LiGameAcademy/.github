# 老李游戏学院 · Li Game Academy

[English](README.md) | 简体中文

通过真实项目学习游戏开发，分享实践经验，一起进步。

老李游戏学院是由老李发起的游戏开发教学与开源社区。我们围绕 Godot 4 制作实战教程、可运行示例、可复用工具与开发拆解，服务独立游戏开发者。组织内同时包含 GDScript 与 C# 项目。

## 从这里开始学习

- [图文教程库](https://github.com/LiGameAcademy/laoli_gamedev_godot4_course)：图文教程、配对工程与课程材料，涵盖 Godot 入门、ARPG、对话与任务、RTS、回合制战斗等主题。
- [Godot 教程示例](https://github.com/LiGameAcademy/godot_tutorial_examples)：配合 Godot 入门课程使用的示例工程。
- [独立游戏观察](https://github.com/LiGameAcademy/IndieGameWatch)：独立游戏的设计、开发与美术分析拆解。

目前图文课程以中文为主，各仓库的英文翻译覆盖程度不同。

## 探索我们的项目

### 工具与玩法系统

| 项目 | 主要内容 |
| --- | --- |
| [GDDataForge](https://github.com/LiGameAcademy/GDDataForge) | 游戏数据加载与管理，支持 CSV、JSON 等格式 |
| [Godot Core System](https://github.com/LiGameAcademy/godot_core_system) · [C# 版](https://github.com/LiGameAcademy/godot_core_system_cs) | Godot 项目的模块化基础框架 |
| [Godot Ability System](https://github.com/LiGameAcademy/godot_ability_system) · [C# 版](https://github.com/LiGameAcademy/godot_ability_system_cs) | 可复用的游戏能力系统 |
| [老李对话系统](https://github.com/LiGameAcademy/laoli_dialogue_system) | 支持本地化的数据驱动对话与任务系统 |
| [回合制战斗系统](https://github.com/LiGameAcademy/godot4_turn_based_combat_system) | 回合制战斗架构实战 |
| [Godot Hex Map](https://github.com/LiGameAcademy/godot_hex_map) | 六边形网格地图 |

### 游戏与教学 Demo

- [GodotRogueMatcher](https://github.com/LiGameAcademy/GodotRogueMatcher)：结合 Roguelite 技能与构筑的五子连线游戏，同时作为 AI 辅助开发教学项目。
- [Nutbound](https://github.com/LiGameAcademy/nutbound)：以寻找家园的橡果为主角、采用林地题材的 Roguelike 卡牌构筑游戏。
- [简易 ARPG](https://github.com/LiGameAcademy/godot_simple_arpg_demo)：动作角色扮演教学 Demo。
- [塔防](https://github.com/LiGameAcademy/GodotTowerDefense) · [C# Demo](https://github.com/LiGameAcademy/godot_tower_defense_cs)：塔防游戏教学项目。
- [小飞机](https://github.com/LiGameAcademy/GodotTappyPlane) · [2D 平台跳跃](https://github.com/LiGameAcademy/GodotPlatform2D) · [库存 UI](https://github.com/LiGameAcademy/GodotSimpleInventory)：围绕具体功能展开的实战示例。
- [Godot Warcraft 3](https://github.com/LiGameAcademy/godot_warcraft3) · [RTS Kernel C#](https://github.com/LiGameAcademy/rts_kernel_cs)：RTS 玩法实现与架构探索。

各项目处于不同开发阶段。使用前请阅读对应仓库，确认支持的 Godot 版本、启动步骤、许可证与当前状态。
